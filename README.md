# LipatoS - Уникальные предметы

Модуль для **Foundry Virtual Tabletop 14** и **D&D 5e**, содержащий автоматизацию уникальных предметов мира Aindor.

## Версия

**1.4.1**

## Совместимость

- Foundry VTT: **14**
- D&D 5e: **6.0.0–6.0.5**, проверено с **6.0.5**

## Багряная мантия

Текущая сборка содержит автоматизацию **Багряной мантии**:

- мантия запоминает заклинание **1–3 уровня**, которое только что использовал персонаж;
- запомненное заклинание можно повторить через действие **«Багряное эхо»**;
- повтор не расходует ячейку заклинания;
- использование тратит **1 заряд мантии**;
- заряд хранится в стандартных зарядах предмета D&D5e и виден в инвентаре;
- после **продолжительного отдыха** заряд полностью восстанавливается;
- запомненное заклинание действует до окончания следующего хода персонажа;
- название действия автоматически показывает, какое заклинание сейчас запомнено;
- мантия должна быть надета.

## Совместимость со старыми предметами

Внутренний ID модуля **намеренно сохранён `aindor-unique-items`**. На него завязаны флаги уже созданной Багряной мантии и состояние запомненного заклинания.

Также сохранена совместимость со старым ID автоматизации `bagryanaya-mantiya-echo`.

При загрузке мира ГМ модуль автоматически приводит существующую Багряную мантию к актуальной схеме зарядов предмета D&D5e: один заряд, восстановление после продолжительного отдыха и расход заряда через предмет.

## D&D5e 6.0.5

Используемые модулем хуки `dnd5e.preUseActivity` и `dnd5e.postUseActivity`, система Activities, `system.uses` и расход `itemUses` проверены на структуре **D&D5e 6.0.5**.

`https://raw.githubusercontent.com/Lipatosha/LipatoS-unique-items/main/module.json`
